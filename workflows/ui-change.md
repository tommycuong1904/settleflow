# UI Change Workflow

## Goal

Modify the interface while preserving the design system.

## Process

1. Locate the affected page.
2. Locate the rendering component.
3. Inspect direct child components only if necessary.
4. Reuse existing components.
5. Implement the visual change.
6. Validate responsiveness.

## Rules

- Never redesign the page.
- Never inspect unrelated pages.
- Reuse spacing.
- Reuse typography.
- Reuse colors.
- Do not introduce a different visual language.
